## 对下一阶段的建议

M21 建议继续顺着 quick start 往前走，但不要突然切成复杂系统。

更稳妥的方向有三种，可择其一：

### 方向 A：quick start 推进链再细一层

目标：

- 让 follow-up 不只是一条“下一步”，而开始表达“先补结构 / 先补反馈 / 先补氛围”这类推进类型

适合原因：

- 最贴合 M20 的自然延续
- 对现有生成链路改动最小

### 方向 B：quick start 与 spotlight 关系再强化

目标：

- 让 quick start 更明确告诉用户：当前这条线优先对应哪条路线，做完后再切到哪条路线

适合原因：

- 可以把 quick start 和专题路线的关系进一步做实

### 方向 C：quick start 开始表达“适合当前不适合当前”

目标：

- 继续强化 quick start 的轻量判断能力，比如“现在先不上什么、后面再补什么”

适合原因：

- 能继续增强 quick start 的决策属性
