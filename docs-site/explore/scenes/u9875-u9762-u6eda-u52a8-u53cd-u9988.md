# 场景 · 页面滚动反馈

- 维度：场景
- 收录案例：1
- 代表案例：[滚动阅读进度条](/demos/other/scroll-reading-progress-bar)

## 为什么从这里开始

适合在滚动驱动页面、长屏内容和过渡式展示页里寻找更明确的滚动反馈。

## 什么时候从这里进入

- 当滚动本身就是页面体验的一部分，而不只是单纯位移时，可以从这里开始。
- 当你希望用户知道自己滚到了哪里，或者当前切换处于什么阶段时，这个场景最有帮助。

## 挑选建议

- 如果页面内容以阅读为主，优先用轻量进度反馈。
- 如果页面内容更偏展示或叙事，再考虑加入更强的滚动驱动动效。
