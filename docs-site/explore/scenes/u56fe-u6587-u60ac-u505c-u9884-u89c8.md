# 场景 · 图文悬停预览

- 维度：场景
- 收录案例：1
- 代表案例：[里程图片展示 · 1](/demos/hover-transition/milestone-gallery-1)

## 为什么从这里开始

适合在图文封面、案例缩略入口和 hover 预览里寻找更轻量的内容预览方式。

## 什么时候从这里进入

- 当页面需要先给用户一点内容感，再决定是否进入详情时，可以从这里开始。
- 当你正在比较“只用静态缩略图”还是“加入悬停预览”两种入口方式时，这个场景最有帮助。

## 挑选建议

- 如果信息密度已经很高，优先选反馈轻一点的预览方式。
- 如果图片本身就是内容重点，可以把预览强度适当拉高，但要先检查可读性。
