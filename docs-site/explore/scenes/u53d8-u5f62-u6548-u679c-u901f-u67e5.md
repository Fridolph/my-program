# 场景 · 变形效果速查

- 维度：场景
- 收录案例：1
- 代表案例：[CSS Transform 效果一览](/demos/hover-transition/css-transform-gallery)

## 为什么从这里开始

适合在 transform 选型和基础空间反馈判断中快速对比不同变形方式。

## 什么时候从这里进入

- 当你已经知道要加一点空间感或反馈，但还没想清楚具体用哪种变形时，可以从这里开始。
- 当你需要和团队快速讨论某种 transform 会带来什么视觉结果时，这个场景很适合作为参考。

## 挑选建议

- 先决定你需要的是方向感、缩放感还是倾斜感，再选对应案例。
- 如果组件里还有文字和图标，优先选对可读性影响更小的变形方式。
