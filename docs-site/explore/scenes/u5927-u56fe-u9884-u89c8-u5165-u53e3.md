# 场景 · 大图预览入口

- 维度：场景
- 收录案例：1
- 代表案例：[分栏式人物画廊](/demos/hover-transition/split-panel-gallery)

## 为什么从这里开始

适合在大图展示、案例预览和封面切换场景中寻找“入口与预览并列”的组织方式。

## 什么时候从这里进入

- 当页面需要让用户快速扫过多个入口，并停留查看某一个重点预览时，可以从这里进入。
- 当你正在做图库、专题页或视觉型目录页，这个场景很适合先看。

## 挑选建议

- 如果预览内容比入口更重要，优先保证主展示区的稳定性。
- 如果入口项会很多，先确认布局在窄屏下是否还能保持切换效率。
