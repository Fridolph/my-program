# 专题路线 · 首屏与品牌感建立

适合在首页首屏、作品集首页和品牌型着陆页里建立第一眼的氛围、导航感和视觉记忆。

## 为什么从这里开始

- 如果你的页面首先要解决“第一眼有没有气质和方向”，这条路线最适合先进入。
- 它把首屏氛围、导航交互和作品集入口放在同一条线里，更容易判断视觉和结构该怎么配合。
