# 专题路线 · 阅读与进度反馈路线

适合在长文、页面滚动、加载反馈和逐步资源进入中寻找更完整的节奏型反馈方案。

## 为什么从这里开始

- 如果你正在做长内容、滚动反馈或等待态，这条路线能比单看某一个 scene 更快建立全局判断。
- 它把阅读、滚动和加载反馈放在一起，适合比较不同节奏型提示到底该怎么选。
