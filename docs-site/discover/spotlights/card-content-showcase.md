# 专题路线 · 卡片与内容展示入口

适合在内容卡片、人物入口、图文悬停和图片浏览中寻找更完整的内容展示路线。

## 为什么从这里开始

- 如果你的页面主要依赖卡片承担内容入口，这条路线更适合作为第一批参考集合。
- 它能同时回答“卡片长什么样”和“卡片如何承接内容流转”这两个问题。
