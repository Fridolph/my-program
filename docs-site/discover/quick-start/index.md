# 快速开始

这里不是按目录找，也不是重搜索。

它更适合回答一个更直接的问题：

> 我现在正在做什么页面，应该先从哪里开始看？

## 按角色开始

      <small>更适合先把一个局部组件做稳定，再决定是否继续扩成更完整页面。 常见下一步：补内容入口 / 补首屏氛围。</small>

      <small>更适合已经进入阅读体验、等待反馈和信息节奏打磨阶段的页面。 常见下一步：补局部动效 / 补内容入口。</small>

      <strong>内容策划</strong>

      <small>更适合需要先排清楚卡片信息层级、预览策略和内容组织方式的场景。 常见下一步：补反馈节奏 / 补首屏氛围。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/roles/frontend-implementation">

      <span>3 条起步线 · 补反馈节奏</span>
      <small>更适合已经准备动手搭页面、搭交互，并希望先确认实现顺序和入口结构的同学。 常见下一步：补反馈节奏 / 补内容入口。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/roles/frontend-practice">

      <span>1 条起步线 · 补内容入口</span>
      <small>更适合先做低成本练手案例，用最小反馈验证动效原理和交互手感。 常见下一步：补内容入口 / 补首屏氛围。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/roles/visual-exploration">
      <strong>视觉探索</strong>

      <small>更适合先判断氛围、品牌感和第一眼视觉层次，再决定如何收进真实页面结构。 常见下一步：补反馈节奏 / 补内容入口。</small>
    </a>

      <small>主结构已经可用，当前更适合补反馈、首屏氛围和细节节奏。 常见下一步：补内容入口 / 补反馈节奏。</small>
    </a>

      <small>更适合回看加载、阅读提示和节奏说明，减少用户上线前的不确定感。 常见下一步：补局部动效 / 补内容入口。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/stages/validation">
      <strong>验证期</strong>

      <small>先验证方向是否成立，优先追求最小可判断结果，而不是一次做满。 常见下一步：补反馈节奏 / 补内容入口。</small>
    </a>
  </div>

## 按下一步推进类型开始

<div class="topic-card-grid">
    <a class="topic-card" href="/discover/quick-start/follow-up/content-entry">
      <strong>补内容入口</strong>
      <span>3 条推进顺序 · 6 类角色</span>
      <small>更适合先把卡片、摘要、预览和列表层级补稳，再继续扩展页面内容入口。 常见角色：前端实现 / 内容策划</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/follow-up/feedback-flow">
      <strong>补反馈节奏</strong>
      <span>2 条推进顺序 · 4 类角色</span>
      <small>更适合先补阅读反馈、滚动提示和资源进入节奏，减少用户浏览时的不确定感。 常见角色：前端实现 / 内容策划</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/follow-up/hero-atmosphere">
      <strong>补首屏氛围</strong>
      <span>2 条推进顺序 · 5 类角色</span>
      <small>更适合回到首页首屏、导航组织和第一眼品牌感，把整体氛围层继续补强。 常见角色：前端实现 / 内容策划</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/follow-up/micro-motion">
      <strong>补局部动效</strong>
      <span>1 条推进顺序 · 4 类角色</span>
      <small>更适合先用低成本动效补一点局部反馈，再决定是否继续扩成更完整的视觉层。 常见角色：内容体验 / 前端练手</small>
    </a>
  </div>

## 按问题开始

<div class="topic-card-grid">
    <a class="topic-card" href="/discover/quick-start/hero-first-screen">

      <small>适合先判断首屏氛围、导航组织和第一眼品牌感该如何配合。 适合：品牌首页 / Landing Page</small>

    <a class="topic-card" href="/discover/quick-start/card-list-and-preview">
      <strong>我想先做卡片列表与内容预览</strong>
      <span>低到中等投入 · 2 条路线</span>
      <small>适合先判断卡片入口、作品集列表、人物卡片和预览切换应该如何分层。 适合：内容列表页 / 案例集</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/reading-and-loading-feedback">
      <strong>我想先做阅读与加载反馈</strong>
      <span>低投入 · 2 条路线</span>
      <small>适合先比较阅读进度、滚动反馈、加载节奏和资源进入提示。 适合：文档页 / 教程页</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/lightweight-animation-practice">
      <strong>我想先找低成本练习案例</strong>
      <span>低投入 · 1 条路线</span>
      <small>适合先从轻量动画、基础 transform 和小型组件反馈开始练手。 适合：动效练手 / 组件试验</small>
    </a>
  </div>

    <a class="topic-card" href="/discover/quick-start/hero-first-screen">

      <small>首屏方向跑通之后，下一步通常要继续把卡片入口、内容预览或列表结构补稳。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/card-list-and-preview">
      <strong>我想先做卡片列表与内容预览 -&gt; 我想先做阅读与加载反馈</strong>
      <span>低到中等投入 · 补反馈节奏</span>
      <small>列表结构稳定之后，下一步通常要继续补阅读反馈、滚动反馈或资源进入节奏。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/reading-and-loading-feedback">
      <strong>我想先做阅读与加载反馈 -&gt; 我想先做卡片列表与内容预览</strong>
      <span>低投入 · 补内容入口</span>
      <small>反馈节奏跑通之后，下一步常常要回到内容入口本身，把卡片、摘要和预览层级一起整理稳定。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/lightweight-animation-practice">

      <span>低投入 · 补首屏氛围</span>
      <small>单点动效练熟之后，下一步通常会回到真实页面入口，比如首屏氛围或导航组织。</small>
    </a>

## 当前先不急着补什么

<div class="topic-card-grid">
    <a class="topic-card" href="/discover/quick-start/hero-first-screen">
      <strong>我想先做首页首屏 -&gt; 先不上 当前还没有补充</strong>
      <span>中等投入 · 补局部动效</span>
      <small>在首屏入口和整体氛围都还没站稳前，先不要急着补局部动效，否则很容易把注意力打散。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/card-list-and-preview">
      <strong>我想先做卡片列表与内容预览 -&gt; 先不上 当前还没有补充</strong>
      <span>低到中等投入 · 补局部动效</span>
      <small>当列表密度、摘要层级和图片比例还没稳定之前，先不要急着补局部动效，否则很容易让浏览节奏变乱。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/reading-and-loading-feedback">
      <strong>我想先做阅读与加载反馈 -&gt; 先不上 当前还没有补充</strong>
      <span>低投入 · 补首屏氛围</span>
      <small>如果当前核心问题是阅读反馈或等待提示，先不要回头做过重的首屏氛围，否则会把注意力从反馈问题上拉走。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/lightweight-animation-practice">
      <strong>我想先找低成本练习案例 -&gt; 先不上 当前还没有补充</strong>
      <span>低投入 · 补反馈节奏</span>
      <small>如果你现在还只是在做低成本练手，先不要急着补阅读或加载反馈，因为这类反馈更依赖真实内容和等待过程。</small>
    </a>
  </div>

## 为什么当前先补这一类

<div class="topic-card-grid">
    <a class="topic-card" href="/discover/quick-start/hero-first-screen">
      <strong>补内容入口 &gt; 补局部动效</strong>
      <span>我想先做首页首屏</span>
      <small>当首屏入口和主视觉关系还没站稳前，先补内容入口会比先补局部动效更容易守住第一眼判断。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/card-list-and-preview">
      <strong>补反馈节奏 &gt; 补局部动效</strong>
      <span>我想先做卡片列表与内容预览</span>
      <small>当列表浏览节奏还在建立时，先补反馈节奏会比先补局部动效更能帮助用户保持阅读连续性。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/reading-and-loading-feedback">
      <strong>补内容入口 &gt; 补首屏氛围</strong>
      <span>我想先做阅读与加载反馈</span>
      <small>当反馈问题已经暴露出来时，先回到内容入口整理结构，会比先补首屏氛围更容易把问题收口。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/lightweight-animation-practice">
      <strong>补首屏氛围 &gt; 补反馈节奏</strong>
      <span>我想先找低成本练习案例</span>
      <small>当练手结果准备接回真实页面时，先补首屏氛围会比先补反馈节奏更容易建立整体方向。</small>
    </a>
  </div>

## 当前最容易做过头的地方

<div class="topic-card-grid">
    <a class="topic-card" href="/discover/quick-start/hero-first-screen">
      <strong>小心做过头：补首屏氛围</strong>
      <span>我想先做首页首屏</span>
      <small>这一条线最容易做过头的，是在首屏里堆太多视觉元素，结果反而把第一条入口和品牌判断一起压掉。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/card-list-and-preview">
      <strong>小心做过头：补局部动效</strong>
      <span>我想先做卡片列表与内容预览</span>
      <small>这一条线最容易做过头的，是在卡片密度、摘要长度和图片比例还没稳时就先堆 hover 与遮罩反馈。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/reading-and-loading-feedback">
      <strong>小心做过头：补反馈节奏</strong>
      <span>我想先做阅读与加载反馈</span>
      <small>这一条线最容易做过头的，是同时把阅读反馈和加载反馈都做得很强，最后形成两套竞争提示。</small>
    </a>
    <a class="topic-card" href="/discover/quick-start/lightweight-animation-practice">
      <strong>小心做过头：补局部动效</strong>
      <span>我想先找低成本练习案例</span>
      <small>这一条线最容易做过头的，是在还没弄清楚反馈服务什么内容之前，就不断叠视觉效果。</small>
    </a>
  </div>
