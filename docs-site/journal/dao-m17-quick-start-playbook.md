- 类型：开发笔记

## 摘要

- 这一轮继续深化 quick start，让它不只告诉用户先去哪里，也开始告诉用户第一步怎么做、怎么选、先避开什么。
- 核心变化是补齐任务型建议字段，并让首页开始直接展示具体 quick start 条目。
