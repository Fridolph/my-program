## 摘要

- 这一轮继续深化 quick start，让它不只告诉用户下一步补什么、先不上什么，也开始回答为什么当前先补这一类。
- 核心变化是补齐 tradeoffNotes，并把推进取舍说明接回 quick start 详情页、聚合页、首页与 discover。
