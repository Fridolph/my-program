- 日期：2026-03-15
- 类型：开发笔记

## 摘要

- 这一轮新增 quick start 总览页与详情页，把“我现在先做什么”直接变成入口，而不要求用户先理解站点结构。
- 核心变化是建立问题起步线，并让其继续回流到 spotlight、scene、demo 与开发笔记。
