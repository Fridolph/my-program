## 摘要

- 这一轮继续深化 quick start，让它不只帮助用户找到入口，也开始帮助用户在第一版之后知道下一步该往哪里接。
- 核心变化是补齐 followUpSlugs 与 followUpReason，并把串联建议接回 quick start 详情页、总览页、首页与 discover。
