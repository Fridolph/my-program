# VitePress 首页精选封面策展任务拆解

## 背景

首页精选已经从顺序截取升级为 metadata 驱动编排，但当前精选卡片仍然主要依赖标题、描述和标签来表达差异。

这会带来两个问题：

- 首页虽然已经有“策展逻辑”，但视觉层仍然不够像 showcase。
- 不同 demo 的第一印象仍然偏文字化，难以在首页快速建立辨识度。

所以这一轮要继续把首页精选从“文本策展”推进到“视觉策展”。

## 本轮目标

- 给精选 demo 增加封面 metadata。
- 支持首页精选卡片展示封面图或渐变封面。
- 保留没有封面 metadata 时的安全兜底。
- 让首页精选在视觉上更像作品集入口。

## 任务拆解

### T1：定义封面 metadata 结构

要求：

- 支持图片型封面。
- 支持渐变型封面。
- 支持简短封面标题或标语。

### T2：接入 registry

- 让 cover 字段进入 metadata 合并链路。
- 对 cover 结构做基本校验。
- 保证 preset / override 都可以配置 cover。

### T3：更新首页生成逻辑

- 首页精选卡片增加封面区域。
- 优先渲染图片或渐变封面。
- 没有封面配置时，回退到统一的轻量占位样式。

### T4：补首批精选封面

优先给已 featured 的首页 demo 增加封面配置：

- 动画类 demo 用渐变和关键词强化节奏感。
- Canvas 类 demo 优先体现互动或图形主题。
- 布局和交互类 demo 用更清晰的结构型视觉表达。

### T5：补样式与说明文档

- 调整首页精选卡片视觉层次。
- 说明 cover metadata 的使用场景和边界。

### T6：沉淀开发记录

- 记录为什么首页需要从“文本策展”进入“视觉策展”。
- 记录 cover 和 featured 的职责关系。
- 记录当前只做首页卡片封面，不扩散到全站的边界。

## 验收标准

- 首页精选卡片支持 cover metadata。
- cover 结构有基础校验。
- 精选 demo 至少有一批可见的视觉封面。
- 生成与构建通过。
- 文档和技术博客同步补齐。
