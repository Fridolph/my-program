# VitePress 首页精选封面资源化任务拆解

## 背景

首页精选已经具备 cover metadata 和渐变封面能力，但目前封面仍然主要依赖纯渐变表达，存在两个限制：

- 封面风格虽然有区分，但仍然偏抽象，不够像真正的作品封面。
- 渐变层没有形成独立资产，后续如果想扩展首页、分类页或社交分享，很难复用。

所以这一轮继续把首页精选封面从“样式效果”推进到“可复用资源”。

## 本轮目标

- 为精选 demo 生成真实的 SVG 封面资源。
- 让 image cover 成为首页精选默认使用方式。
- 保留 gradient cover 作为兜底能力。
- 让封面资源可复用到后续分类页或分享图场景。

## 任务拆解

### T1：定义封面资源目录与生成策略

- 新增统一封面资源输出目录。
- 约定文件命名与 demo id 对齐。
- 让生成脚本负责批量产出 SVG 资源。

### T2：设计封面资源数据结构

- 在 metadata 中增加可用于生成 SVG 的字段。
- 封面资源仍然由 cover metadata 驱动，而不是手工维护大量静态文件。
- 保持 image / gradient 双轨兼容。

### T3：实现 SVG 封面生成脚本

- 根据 featured demo 的 cover metadata 生成 SVG。
- 生成标题、标签、色板和装饰元素。
- 将资源输出到 `public/featured-covers/`。

### T4：接入首页 image cover

- 让首页优先使用生成后的 image cover。
- gradient cover 作为 fallback。
- 确保首页构建前会自动生成封面资源。

### T5：补首批精选封面资源

- 至少覆盖当前首页精选的那一批 demo。
- 让不同分类封面有可见风格差异。

### T6：沉淀文档与开发记录

- 说明为什么从渐变封面进入资源化封面。
- 说明生成资源与 metadata 的关系。
- 说明当前阶段为什么选择 SVG 而不是位图截图。

## 验收标准

- `public/featured-covers/` 生成真实 SVG 封面。
- 首页精选优先使用 image cover。
- 生成与构建通过。
- 文档和技术博客同步补齐。
